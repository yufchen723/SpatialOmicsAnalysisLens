# Changelog

## 1.0.0 — 2026-10-28

First public release of Spatial Omics Analysis Lens.

- Report with three parts and an appendix; figure blocks with "About this figure"; voice rules (answer first, short bullets, literature context with verified links).
- Provenance: plan.json, run manifests, decisions.jsonl, lineage.json, integrity checks, report_data.json.
- Report Studio: local server (127.0.0.1 + token), overlay with Ask / Edit / Review / Translate, threads, notes placed under their passage, review chips, Versions menu.
- Two current files per report (`__clean`, `__with_notes`), automatic archive, release copies, "Reopen this report in Report Studio" section in every export.
- Report sets with an overview page; project ledger (findings, lineage, question tree, paper bridge).
- Domain modules B1–B14 for omics and spatial-omics data types.
- Settings template; no project-specific defaults in the skill.
